Mendeley - Przewodnik dla Studentow

Skuteczne zarzadzanie literatura naukowa

Ta strona dziala lokalnie i nie wymaga frameworka. Zawiera kroki startowe, dobre praktyki i typowe bledy podczas pracy z Mendeleyem.

Postep: 0 / 5

1. Start i konfiguracja

  1. Zainstaluj Mendeley Reference Manager oraz plugin Citation.
  2. Skonfiguruj konto i folder synchronizowany.
  3. Ustaw styl cytowan (np. APA 7 lub Vancouver).

2. Organizacja biblioteki

Tworz kolekcje tematyczne i tagi. Dodawaj PDF-y partiami, a potem poprawiaj metadane recznie tam, gdzie parser sie myli.

Dobra praktyka: od razu uzupelniaj DOI i rok publikacji.

3. Cytowanie i bibliografia

Wstawiaj cytowania bezposrednio z poziomu edytora tekstu. Bibliografie generuj automatycznie, ale zawsze zrob finalna kontrole formatowania.

4. Wspolpraca zespolowa

Uzywaj grup prywatnych dla projektow badawczych. Ustal wspolne zasady nazewnictwa i wersjonowania notatek.
